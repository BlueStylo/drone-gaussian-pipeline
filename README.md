# Drone Gaussian Pipeline

직접 촬영한 드론 영상으로 집과 동네를 복원한 Apple Silicon Gaussian Splatting 파이프라인입니다.

[공개 3D 데모](https://yangdong-3d.yangdong-3d-public-proxy.workers.dev/) · [로컬 설치](docs/setup.md)

실제 작업은 2026-09-14~21에 진행했습니다. GitHub 이력은 보존된 코드와 실행 기록을 바탕으로 **2026-09-21 현재 날짜에 재구성**합니다. 과거 커밋·리뷰·CI를 꾸미지 않으며 각 PR에서 현재 검사를 실행합니다. 대형 영상·모델과 비공개 서비스 설정은 포함하지 않습니다.
