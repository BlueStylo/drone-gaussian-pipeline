# 측정 결과 · Results

2026-09-19에 직접 촬영한 드론 영상 3개를 사용했다. 먼저 집을 복원하고, 주변 촬영분을 추가해 하나의 Gaussian Splatting 모델을 새로 학습했다. 아래 수치는 당시 완료 기록에서 선별한 값이며, 공개 저장소를 정리하면서 복원을 다시 실행한 결과는 아니다.

## 입력과 프레임 추출

| 입력 | 사용 구간 | 추출·등록 이미지 |
| --- | --- | ---: |
| 집 촬영 A | 20–330초 | 309장 |
| 집 촬영 B | 0–80초 | 80장 |
| 동네 촬영 C | 40–334초 | 293장 |
| **합계** | **하나의 연결된 장면** | **682 / 682장** |

FFmpeg로 1fps, 최대 변 1,600px, JPEG `-q:v 2` 조건으로 추출했다. 결과는 1,600 × 900 이미지다. 사용 구간 지정과 일정 간격 추출을 했으며, AI 선명도 선별을 수행한 것은 아니다. 실행 전 예상값은 683장이었지만 실제 파일·등록 수는 **682장**이다. 컨테이너 길이와 영상 스트림 끝 타임스탬프 차이 때문에 구간 길이가 이미지 개수와 항상 같지는 않다.

## 집에서 동네로 확장

| 항목 | 최초 집 복원 | 집 + 주변 동네 |
| --- | ---: | ---: |
| 등록 이미지 | 389 / 389 | 682 / 682 |
| COLMAP 희소점 | 169,464 | 344,264 |
| 평균 재투영 오차 | 0.529845px | 0.474761px |
| Brush 학습 단계 | 6,000 | 12,000 |
| 평가 시점 | 39 | 69 |
| Gaussian 수 | 572,927 | 1,688,991 |
| 보관용 PLY | 135.2MB | 398.6MB |
| GPU 학습 시간 | 14분 7초 | 47분 57초 |

기존 집의 389개 이미지와 COLMAP DB·희소 모델을 재사용했다. 새 촬영분 293장을 함께 정렬한 뒤, **집·동네 전체로 새 Gaussian 모델을 학습**했다. 기존 집 PLY를 이어 붙이거나 optimizer 상태를 이어 학습한 방식은 아니다. 촬영 구간 사이의 검증된 이미지 쌍 1,391개를 확인했다.

## 최종 확장 실행 시간

측정 장비는 **Apple M1 Pro / 통합 메모리 32GB**다. COLMAP 정렬은 CPU, Brush 학습은 Metal GPU를 사용했다.

| 단계 | 기록 |
| --- | ---: |
| 새 이미지 293장 추출 | 98.34초 |
| 특징 추출 | 130.05초 |
| 순차 매칭 | 328.16초 |
| 촬영 구간 간 추가 매칭 | 294.42초 |
| 통합 카메라 정합 | 627.78초 |
| 모델 분석 | 1.07초 |
| 왜곡 보정 | 10.43초 |
| **전처리 소계** | **1,490.25초 · 약 24분 50초** |
| **12,000단계 학습** | **2,877.38초 · 약 47분 57초** |
| **실행 단계 합계** | **4,367.63초 · 약 72분 48초** |

이 시간은 **기존 집 데이터가 준비된 상태의 확장 실행**이다. 최초 집 복원, 촬영, 설치, 압축·검사·웹 배포·시연 영상 제작은 포함하지 않는다. 최초 집 복원은 성공 단계 합계 27분 43초, 재시도·대기를 포함한 경과 시간 30분 35초였다. 단계별 원자료는 [timing JSON](../evidence/reconstruction-timing.json)에 있다.

## 웹 모델과 검증

398,603,428바이트의 원본 PLY를 103,505,301바이트의 웹용 PLY로 압축했다. **용량은 74.03% 감소**, Gaussian 1,688,991개와 SH3는 유지했다. 표현값의 양자화를 포함하므로 무손실 압축이라고 부르지 않는다. 점 삭제·다운샘플링·좌표 변환은 하지 않았으며 보관용 원본을 별도로 유지했다.

원본의 모든 float 값에서 NaN/Infinity가 없는지 검사하고, 압축 전후 점 개수·SH 차수·본문 길이를 확인했다. 공개 주소에서 내려받은 103.5MB 모델의 SHA-256도 보관된 웹 모델과 일치했다. 브라우저에서 집 정면, 동네 시점 선택, 집 정면 복귀를 확인했다. [측정 JSON](../evidence/town-run.json) · 전송·뷰어 검증 (`../evidence/delivery-verification.json` — 후속 공개 단계에서 추가)

69개 평가 시점의 별도 PNG 비교 PSNR 평균은 26.85dB였다. Pillow로 참조 이미지를 맞춘 외부 참고 지표이므로 Brush 내부 지표나 다른 프로젝트의 벤치마크와 직접 비교하지 않는다.

## 한계

촬영된 집과 주변 도로·주택·논밭 범위의 시각적 복원이다. 행정구역 전체를 복원한 결과는 아니다. 가려진 면, 유리, 움직이는 나무, 먼 산과 하늘에는 흐림·빈 영역·늘어진 점이 남는다. 촬영 경로에서 크게 벗어나면 품질이 떨어질 수 있다.

재투영 오차는 이미지 정합의 픽셀 오차이며 실제 거리의 측량 정확도가 아니다. CAD, 닫힌 표면 메시, 충돌 모델을 제공하지 않는다. 모바일 실기기 성능과 다수 동시 접속 성능은 별도 검증이 필요하다.

## 선행 Mac 샘플 시험

2026-09-14에는 65.5초짜리 공개 신발 촬영 샘플을 사용해 Mac 파이프라인을 먼저 검증했다. 131 / 131장 등록, 4,000단계 학습, 281,719개 Gaussian, 총 변환 366.15초를 기록했다. **드론 영상이 아닌 짧은 정물 시험**이며 넓은 지역의 품질·시간을 예측하는 기준으로 쓰지 않는다. 원본 샘플이나 생성 모델은 이 저장소에서 재배포하지 않는다. [샘플 측정](../evidence/sample-run.json) · [출처](provenance.md)
